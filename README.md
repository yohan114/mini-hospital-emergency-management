# Mini Hospital Emergency Management System

CIT300 - Data Structures and Algorithms | Individual Mid Assignment

A console based hospital emergency management system written in Java, built on four
data structures that are implemented from scratch (no `java.util` collection classes):

| Module                | Data structure     |
|-----------------------|--------------------|
| Patient records       | Binary Search Tree |
| Emergency unit        | Queue (FIFO)       |
| Treatment history     | Stack (LIFO)       |
| Patient visit history | Singly Linked List |

## Build and run

```
run.bat        (Windows)
./run.sh       (Linux / macOS / Git Bash)
```

Full documentation is added as the project is developed.
